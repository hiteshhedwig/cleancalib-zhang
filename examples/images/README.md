# Demo input images

## `leena.png`

The user supplied this `400 × 400` RGBA PNG for local computer-vision demos.
It is currently used by:

- Milestone 1: lossless image load/save round trip
- Milestone 2: grayscale conversion and side-by-side comparison

Future image-processing demos such as gradients, corner response, and feature
overlays may also use it when checkerboard-specific content is not required.
Calibration and checkerboard-detection demos still require actual checkerboard
images.

recorded in this repository. Confirm redistribution rights before publishing
or distributing the binary as part of a public release.
